ShazamX

v0.4.0 · mrnik12

Restores song recognition in older versions of Shazam.

Compatibility

iOSShazam version
iOS 65.5.1
iOS 77.2.0
iOS 8–107.2.0
May work · Untested

Install the matching version of Shazam first. Song recognition requires internet access.

Features

  • Song recognition

    Tap the Shazam dial to see the song title, artist, and cover art.

  • My Tags

    Find saved songs in Shazam. On 7.2.0, tap Add to Tags to save a match.

  • Settings

    Enable the tweak or choose a recognition server under Settings › ShazamX.

Changelog
